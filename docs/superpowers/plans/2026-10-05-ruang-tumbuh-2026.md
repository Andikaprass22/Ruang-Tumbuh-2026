# Ruang Tumbuh 2026 Landing Page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** Build a responsive, visually distinctive Vite + React + TypeScript
landing page for the "Ruang Tumbuh 2026" seminar & workshop that doubles as a
sellable event-template, with all content centralized in `src/lib/`.

**Architecture:** A single-page Vite SPA (no router). Hero → countdown → about →
speakers → agenda → tickets → location → FAQ → registration → closing CTA →
footer, all reachable via in-page anchors with smooth scroll. All copy, event
identity, speakers, agenda, tickets, audience profiles, and FAQs live in typed
modules under `src/lib/`; components only render that data. Styling is Tailwind
CSS v4 with a CSS-first `@theme` block as the single restyle point. Pure helpers
(countdown math, WhatsApp links, price formatting) are unit-tested with Vitest;
UI is verified by typecheck, lint, build, and a manual checklist.

**Tech Stack:** Vite, React 19, TypeScript (strict), Tailwind CSS v4
(`@tailwindcss/vite`), Vitest, ESLint, Agentation (dev-only). **No
`react-router-dom`.**

**Spec:** `docs/superpowers/specs/2026-10-05-ruang-tumbuh-2026-design.md`

## Global Constraints

- **No git commits.** Skip every commit step; replace it with the task's
  build/lint checkpoint.
- No backend, no database, no payment integration, no admin CRUD.
  `src/lib/data.ts` is the only source of truth for content; `src/lib/site.ts`
  for event identity/contact.
- TypeScript strict mode on; no `any` in application code.
- All user-facing copy and demo content is in **Indonesian**; code identifiers,
  comments, and this plan are in English.
- Money is an integer in IDR; always rendered through `formatRupiah`. `0` is
  rendered as `"Gratis"` at the component level.
- WhatsApp number lives in `src/lib/site.ts` in international format, digits
  only (no `+`, spaces, or dashes).
- Every interactive element must have a real target or action — no `href="#"`
  placeholders.
- Demo images are local SVG files under `public/img/`; never hotlink external
  images.
- **No invented participant counts, no "kuota terbatas"/scarcity, no verified
  or guaranteed-outcome claims.** Speaker blurbs describe topics, not fabricated
  credentials.
- Motion is restrained and opt-in; everything must be correct under
  `prefers-reduced-motion: reduce`.
- Breakpoints are Tailwind defaults; mobile-first, collapse navbar below `md`.

## Review Focus

Uncovered input classes most likely to bite a real user, most likely first. Each
gets a test in the owning task:

1. `siteConfig` WhatsApp number empty → register/ticket buttons must fall back to
   the registration form / email, never emit a broken `wa.me` link. (Task 2, Task 10)
2. Countdown at or after the event start → must **stop ticking** and show
   `"live"`/`"ended"` status, never negative digits. (Task 2, Task 6)
3. Invalid or missing `startISO`/`endISO` → countdown must degrade to `"ended"`
   with zeros, never `NaN` or a crash. (Task 2)
4. An agenda item whose `speakerId` points at a missing speaker → the row must
   still render (title/time/track) without the speaker name, never crash.
   (Task 3, Task 8)
5. Registration submitted with no ticket selected → message must still name the
   event and use a generic line, not break. (Task 2, Task 10)
6. Very long ticket name or large price at 320px width → layout must not
   overflow horizontally. (Task 11)

```ts
// src/lib/countdown.test.ts
import { describe, it, expect } from "vitest";
import { getCountdown } from "./countdown";

const START = "2026-11-14T09:00:00+07:00";
const END = "2026-11-14T16:00:00+07:00";

describe("getCountdown", () => {
  it("counts down while the event is upcoming", () => {
    const now = new Date("2026-11-14T08:59:59+07:00");
    const c = getCountdown(START, END, now);
    expect(c.state).toBe("upcoming");
    expect(c.seconds).toBe(1);
  });
  it("splits a multi-day gap into days/hours/minutes/seconds", () => {
    const now = new Date("2026-11-12T07:58:57+07:00"); // 2d 1h 1m 3s before
    const c = getCountdown(START, END, now);
    expect([c.days, c.hours, c.minutes, c.seconds]).toEqual([2, 1, 1, 3]);
  });
  it("is 'live' at exactly the start and zeroes the parts", () => {
    const c = getCountdown(START, END, new Date(START));
    expect(c.state).toBe("live");
    expect([c.days, c.hours, c.minutes, c.seconds]).toEqual([0, 0, 0, 0]);
  });
  it("is 'ended' after the end (Review Focus #2)", () => {
    const c = getCountdown(START, END, new Date("2026-11-15T00:00:00+07:00"));
    expect(c.state).toBe("ended");
    expect([c.days, c.hours, c.minutes, c.seconds]).toEqual([0, 0, 0, 0]);
  });
  it("never returns negative parts (Review Focus #2)", () => {
    const c = getCountdown(START, END, new Date("2026-12-01T00:00:00+07:00"));
    expect(c.days >= 0 && c.hours >= 0 && c.minutes >= 0 && c.seconds >= 0).toBe(true);
  });
  it("degrades to 'ended' on an invalid date (Review Focus #3)", () => {
    const c = getCountdown("bukan-tanggal", END, new Date());
    expect(c.state).toBe("ended");
    expect(Number.isNaN(c.seconds)).toBe(false);
  });
});
```
